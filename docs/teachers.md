# 教师档案

入口：侧栏「教师档案」或 `/sms#teachers`。

- 档案绑定一个已有 Hydro UID，每个 UID 最多一份教师档案；非空工号唯一。创建账号仍使用账户管理页。
- 基本字段为姓名、工号、性别、校区和在职状态；联系方式为电话、微信，另有内部备注。
- 插件管理员默认可管理全部档案；也可按 `teachers.read/create/update/sensitive` 分别授权基本查看、新建、修改和敏感资料查看。教师默认只查看本人档案及联系方式，不能编辑；内部备注仅向有敏感资料权限的其他账号展示，本人即使是管理员也不能读取或写入自己的内部备注。未提交联系资料的基本资料修改保留原值。
- 列表只返回基本资料和当前任教班级。班级详情与排课筛选使用教师姓名，不包含联系方式或内部备注。
- 已有任课教师没有档案时显示「待建档」。此状态由当前班级身份推导，读取时不创建资料。
- 建立教师档案、修改在职状态均不授予或撤销班级任课教师身份、学生资料权限或账号权限，这些操作由对应管理入口处理。
- 新增使用请求标识防止重试重复创建，编辑使用版本校验防止覆盖；读写敏感资料记入审计，审计不保存资料正文。

接口复用 Hydro 会话及插件同源校验：

- `GET /sms/api/teachers?q=&status=&page=`：分页查询；普通教师只返回本人。
- `POST /sms/api/teachers`：具备教师创建和读取权限者新建。
- `GET /sms/api/teachers/:id`：有基本资料读取权限者或本人查看，敏感字段另行过滤。
- `POST /sms/api/teachers/:id`：具备教师修改和读取权限者更新；提交敏感字段还需敏感权限。

数据保存在 `sms_teachers`，不会修改 Hydro 登录信息。

模块授权与默认模板见 [模块权限与鉴权](authorization.md)。教师档案不提供导出。
