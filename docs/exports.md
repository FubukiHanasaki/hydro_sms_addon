# 按功能导出

导出按钮放在对应列表或详情卡片中，没有独立的导出功能页。点击按钮后选择 Excel（XLSX）或 CSV。教师档案不提供导出。

| 位置 | 导出内容 |
| --- | --- |
| 学生档案 | 当前姓名、状态、年级、学校及子域筛选下的学生资料 |
| 班级与子域 | 当前筛选列表；成员弹窗导出当前搜索下的成员与身份 |
| 账户管理 | 当前筛选账号的 UID、用户名、学生姓名、启用及保护状态 |
| 课程管理 / 班级详情 → 实际课程 | 查询日期范围内的实际课程、时间、时长、教师、内容及关联信息 |
| 班级详情 → 考勤 | 当前班级、日期范围内的逐课考勤明细及学生汇总 |
| 排课管理 / 班级详情 → 排课 | 当前教师或班级及日期范围内的课次；当前计划列表 |
| 班级详情 → 概览 | 当前班级及日期范围的指标 |
| 班级详情 → 模拟赛 | 当前班级、日期范围内的 Hydro 比赛列表 |
| 班级详情 → Rating 分析 | 学生 Rating、平均分时间序列、模拟赛涨跌分析分别导出 |
| Rating / 原版排名页 | 当前榜单、搜索与班级筛选下的全部结果 |
| Rating 历史 / 用户资料页 | 指定用户全部历史；历史弹窗可选择近 30 天 |
| 访问授权 / 操作记录 | 插件管理员导出授权策略、审计记录 |
| 批量排课预览 / 结果 | 当前弹窗导出逐行检查结果及已展示的冲突明细 |
| 批量操作结果 | 批次逐行结果，补建账号批次可导出账号与初始密码 |
| 学生导入结果 | 逐行识别及执行结果，已完成批次可导出账号 |

分页列表导出当前已查询筛选下的全部结果，超过 10000 行会提示缩小范围，不只导出当前页。文件最多 20 MB，时间列统一使用北京时间。课次导出按查询日期范围；计划导出沿用当前计划列表，不把计划缩减为当前可见一周。

## 权限与隐私

- 后端重新校验每个模块原有权限。教师只能导出有权管理班级的数据，学生的考勤、班级 Rating 分析只包含本人可见范围。
- 学生资料默认只含基本信息。可勾选「包含有权查看的联系资料」，服务端逐人过滤生日、联系方式及内部备注，无权字段留空；「敏感资料可见」列说明是否可查看。本人即使是管理员也不会得到自己的内部备注。
- 账户导出不含邮箱、认证器、密码散列、登录 IP 或当前密码。账号批次的密码只代表创建时的初始密码；导入绑定既有 UID 时密码列留空。
- Rating 榜单及个人历史保留公开账号名，不加入档案姓名或联系资料；班级分析沿用班级已有的基本名册权限。
- 导出时授权策略变化或相关授权过期会拒绝本次下载。导出使用当前会话，响应私有且禁止缓存。
- CSV 使用 UTF-8 BOM、标准引号转义，并对可能触发公式的文本作转义。Excel 把文本写为字符串，不执行导出数据中的公式；分数等数值保留数值类型。
- 成功生成文件后只写入操作类型、行数和敏感字段选项的审计，不修改学生、账号、课程、考勤或 Rating。

接口为 `GET /sms/api/exports/:kind?format=xlsx|csv&...`，仅作为各模块按钮的共用后端。筛选参数与对应列表一致，页码不限制导出范围。`students` 可带 `sensitive=true`；班级详情使用 `classId/from/to`；跨班课表使用 `teacherUid/from/to`；历史使用 `uid/period`；批次导出使用 `id`。

不再迁移教师评语、学生反馈、知识点掌握和独立公告模块；此前已排除办公工作台和在班时段验证。
