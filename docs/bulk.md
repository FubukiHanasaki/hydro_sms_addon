# 批量操作

仅插件管理员可访问，使用 Hydro 登录会话与插件同源校验。版本号保持 0.2.0。

## 批量升年级

入口：「学生档案」右上角「批量升年级」。操作针对全部符合条件的学生，与列表当前搜索条件无关，确认前展示完整变更名单和跳过原因。

- 年级顺序：一年级至九年级、高一、高二、高三、已毕业。
- 在校学生升一级；高三改为已毕业，学生状态保留。已毕业、离校、空年级及无法识别的年级跳过。
- 休学学生默认跳过，可勾选「本次复学并升年级」，将状态改为在校并升一级。
- 手动预览和确认，无定时自动执行。预览有效期 15 分钟，期间资料变化或其他升年级操作会要求重新预览。
- 距上次执行不足 300 天（包括已撤销批次）或服务器时间回退，须勾选额外确认。
- 不自动修改账号启用状态、班级成员、权限、Rating 或考勤。

「批量记录」可以查看执行结果和撤销。使用递增序号确定执行先后，不受系统时钟回退影响。仅最新未撤销的升年级批次可撤销，支持按相反顺序逐批恢复。撤销前检查所有目标的年级和状态版本；手动改动后即使改回原值也会阻止撤销。无关资料编辑不阻止撤销，也不会被覆盖。

## 批量账户管理

入口：「账户管理」。

- **批量补建账号**：查找没有 Hydro 账号绑定的在校学生。预览分配姓名全拼用户名，重名追加数字；确认后创建普通 Hydro 账号并绑定现有学生档案，初始密码与用户名一致。已绑定、休学或离校学生不建号；不重建档案、不修改既有账号。结果支持导出本批账号 CSV，所列密码为初始密码，不代表之后修改过的当前密码。
- **批量重置密码**：勾选普通账号，可选择本页或跨页累积选择，预览所选 UID、用户名和学生姓名后输入并确认新密码。新密码应用于本批尚未完成的账号；成功后撤销原登录会话。内置账号、插件管理员及额外 Hydro 权限账号不可选择，服务端再次检查保护规则。每批最多 200 个账号。
- 重置密码不在插件数据库、批次记录或审计中保存密码及其散列。关闭页面后不能恢复输入的密码；续办须重新输入密码，只处理未完成的账号。

## 执行记录与恢复

每个操作保存独立批次和逐项结果。确认前做版本及目标校验，重复确认已完成批次不会再次执行。大批学生操作每批最多 2000 人。

当前 MongoDB 无跨集合事务：运行中断或宿主调用失败时可能已经处理部分条目，批次保留「未完成」与错误信息。从「批量记录 → 详情 → 继续处理」续办，已完成条目跳过。Hydro 建号后、档案绑定前发生中断时，通过固定内部邮箱找回同一账号再绑定；账号重置使用逐账号操作标记恢复，不重复处理已经成功的目标。

未完成的升年级、撤销或补建账号批次会暂时阻止其他学生资料写入，避免续办覆盖后续编辑。任意插件管理员都可以续办已开始的批次，预览只允许创建者确认。外部直接改库造成的冲突需要维护人员核对，界面不会擅自覆盖。

存储：`sms_bulk_jobs` 保存预览、目标快照和逐项进度，未执行预览过期后自动清理；`sms_bulk_state` 保存执行序号；`sms_batch_locks` 保存短期互斥锁；学生的 `gradeRevision` 只在年级或状态变化时增加；`sms_account_state` 保存账户版本和恢复标记。审计仅记录操作类型、操作者、批次和字段名。

接口：

- `GET /sms/api/bulk`：最近 100 条已开始批次。
- `POST /sms/api/bulk`：预览，`kind` 为 `promotion`、`provision` 或 `password`；升年级可带 `resumeIds`，重置密码带 `uids`。
- `GET /sms/api/bulk/:id`：结果与明细。
- `POST /sms/api/bulk/:id`：确认或续办；重复升年级带 `confirmWarning: true`，密码重置带 `password`。
- `POST /sms/api/bulk/:id/undo`：确认撤销或续办升年级撤销。
