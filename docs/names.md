# 档案姓名展示

默认身份格式为 `档案姓名 (Hydro用户名)`；没有绑定档案姓名时显示 Hydro 用户名。姓名优先采用教师档案，其次为学生档案，不覆盖 Hydro 账号保存的昵称或用户名。

- 已绑定教师档案的账号、插件管理员、使用「教务」或「只读教务」默认权限模板的账号，可以显示所有用户的档案姓名。
- 尚未绑定教师档案的班级任课教师，在拥有本班学生基本资料读取权限时，可显示本班学生的档案姓名；不扩大到全站，也不解除排名页匿名规则。
- 其他账号查看他人时只显示用户名；查看教师、教务、插件管理员时允许显示其档案姓名。本人仍可看到自己的档案姓名。
- Hydro 超级管理员、子域所有者或临时模块授权本身不会获得全站学生姓名展示权限。绑定和身份变化在后续请求重新检查。
- 姓名展示不授予学生档案、教师联系资料、内部备注或其他业务数据的读取权限。
- 排名页保留原有匿名条件：未绑定学生或教师档案的查看者仍只看到「选手1、选手2」；即使是插件管理员，也不因本项姓名规则自动取消排名匿名。非匿名排名使用上述姓名规则。

用户名组件、个人资料标题、导航、SMS 列表及对应 JSON 采用按请求生成的姓名投影，不修改 Hydro 共享用户缓存。导出仅在有权展示姓名时保留原始姓名，方便重新导入；没有权限时使用用户名。隐藏姓名不参与名称搜索，不通过筛选结果泄漏；没有姓名展示权限的资料编辑不会覆盖原姓名。
