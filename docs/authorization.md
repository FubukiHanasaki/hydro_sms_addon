# 模块权限与鉴权

入口：学生管理 → 访问授权。仅插件管理员可修改默认模板、临时授权、自定义模板和学生专项授权；插件管理员仍由服务器 CLI 维护，不继承任何 Hydro 管理身份。当前版本 0.2.0。

模块权限顶部支持按用户名、绑定的学生姓名、绑定的教师姓名或 Hydro UID 查找账号。精确 UID 或唯一结果直接选中；多个匹配显示候选账号，选中后才能授权。修改搜索词会清除原选择。搜索接口 `GET /sms/api/authorization/accounts?q=...` 仅插件管理员可调用，最多返回 20 个账号的 UID、用户名和绑定姓名，不返回联系方式或认证资料。

## 默认权限与追加授权

账号可以绑定一个默认模板：现有身份权限、教务、任课教师、只读教务、学生本人、无业务默认权限。模板绑定不会修改 Hydro 权限、密码或班级身份。

- **现有身份权限**保留插件此前行为：任课教师管理本班课程考勤，成员在可访问班级查看课表，学生仅看到自己的考勤。教师身份本身不会新增学生档案读写权限。
- **教务**可在全部班级管理学生资料、班级成员及教师分配、教师档案、课程考勤、排课与教务报表。账号管理、Rating 管理、审计、批量升年级和权限管理需单独授权。
- **任课教师**按当前实际加入且被分配为任课教师的班级，查看学生基本资料、课程和报表并登记、修改考勤；不自动查看敏感联系资料，不自动排课。
- **只读教务**可查看并导出一般业务信息；不能写入，不包含敏感资料、账户或审计权限。
- **学生本人**按当前加入的班级查看课表和自己的课程考勤。自己的学生联系资料始终可见，内部备注始终不向本人展示。
- **无业务默认权限**清除模板提供的业务权限；自己的档案读取和已存在的专项/临时授权仍保留。

管理员可新建或修改自定义模板，逐项设置全部班级或任教班级范围。内置模板不可修改。模板不支持委派权限管理或任命插件管理员。

临时授权是**追加**权限：可多条叠加，每条可选多个操作、全部或指定班级、生效时间、失效时间和备注，可独立撤销。页面显示已撤销、已失效及待生效记录。未选失效时间表示长期有效。新建班级、账号、教师档案、批量排课、导入、批量升年级、Rating 管理和审计等全局操作不接受班级范围。

学生专项授权保留原有「指定学生 / 全部学生」范围。与新模板、模块授权相加，不会被模板绑定覆盖。普通模块授权无法委派授权管理本身。

## 决策与边界

`src/authorization.ts` 是权限目录、默认模板、时效计算、范围合并、配置管理及有效权限快照模块，业务服务在读写入口调用，而非只隐藏按钮。

每次请求使用 Hydro 会话确认账号和启用状态，写请求还验证同源 Origin、`X-SMS-Request: 1` 以及 JSON 内容类型。业务层随后计算当前默认模板和已生效授权，再检查操作、班级范围、关联操作、记录版本和资源冲突。未知权限拒绝。没有权限配置时保持原行为，不自动分配教务身份。

- 跨班级写操作必须覆盖所涉及的全部班级。
- 学生基本资料在多个班级共享；按班级授权可读取任一授权班级中的学生，修改、敏感读取和绑定必须覆盖该学生全部非主域成员关系；全局或学生专项授权按其明确范围处理。
- 联系资料与内部备注单独鉴权；仅基本资料授权不会返回敏感字段。教师基本资料修改未提交联系资料时保留原值。
- 课程创建/修改、计划创建/修改需要对应读取权限；关联已有课程还需 `courses.link`、`courses.update` 及对应课程、课表读取权限。新建班级需全局班级创建和读取权限。
- 班外学生补充需 `courses.roster` 及该学生基本资料的读取权限；不验证旧系统的在班时段。
- 修改教师身份或移除教师需同时覆盖成员管理与教师分配权限。
- 学生导入检查导入、新增、读取、修改及绑定权限（基本资料导入不要求敏感资料权限）；批量操作按操作种类逐项检查，续办过程中重新鉴权。
- 各项导出同时检查导出权限和原有读取范围。原有学生专项授权及本人资料导出保持兼容；模板和模块权限的新授权不会自动获得导出能力。
- 导出完成前再次比较当前有效权限，避免过期或撤销后继续交付文件。

不缓存会话内的授权结论。撤销、到期、教师分配和成员变更在后续服务请求立即生效。已打开页面可能仍显示之前的按钮，提交时会再次拒绝，刷新页面可更新显示。

模块配置使用 `sms_authorization` 单文档和独立 revision 做原子替换，防止两个管理员互相覆盖。配置变更及实际拒绝的写操作写入 `sms_audit`，不记录密码、联系方式、完整教学内容或考勤备注。原 `sms_policy` 管理员与学生专项授权保留。

## API

- `GET /sms/api/authorization`：管理员查看目录、模板、绑定和授权。
- `POST /sms/api/authorization`：携带当前 `revision`；`action` 为 `bind`、`template`、`grant`、`revoke`。冲突返回 409。
- `GET /sms/api/authorization/effective`：查看自己的有效操作与范围、模板和专项授权。
- `GET /sms/api/authorization/effective?uid=123`：管理员查看指定账号实际权限。
- `GET /sms/api/exports/module-permissions?format=xlsx|csv`：管理员导出模板、绑定及临时授权，入口在模块权限卡片。

当前身份卡片中的「我的权限」可查看实际权限。配置授权不会创建账号，不改变任何 Hydro 原生比赛、题库等权限。
