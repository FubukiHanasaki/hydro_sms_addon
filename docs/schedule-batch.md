# 批量排课

入口：「排课管理」顶部「批量排课」，需要全局 `schedules.batch` 以及每个目标班级的计划创建与读取权限；插件管理员默认具备。只创建每周排课计划，不生成实际课程、考勤或模拟赛；版本保持 0.2.0。

## 文件与预览

支持 Excel（XLSX、XLS）、CSV 文件，或直接粘贴 CSV。沿用有内存及超时限制的文件解析器，支持工作表选择、中文 CSV、Excel 日期和时间单元格；可下载空 CSV 模板，读取后调整列对应。

每行一条计划，每批 1–100 条，文件最多 2 MB。每个计划支持 1–14 个每周时段；文件里多个星期可写 `1,3,5` 或 `周一、周三、周五`，使用同一开始/结束时间。含逗号的 CSV 单元格须用双引号包裹。通过 API 可提供不同星期、不同时间的 `slots`。

| 字段 | 说明 |
| --- | --- |
| 班级/子域 ID | 必填；也可用唯一班级名称，重名时必须填写 ID |
| 排课名称 | 必填 |
| 教师 UID | 必填，必须是该班当前且已加入子域的任课教师 |
| 开始日期、结束日期 | 必填；ISO 日期、斜线日期或 Excel 日期 |
| 星期 | 必填；1–7 表示周一至周日，可填多个 |
| 开始时间、结束时间 | 必填；HH:mm、H:mm 或 Excel 时间，结束晚于开始 |
| 教室 | 可空；非空同名地点会检查占用 |
| 状态 | 默认进行中，支持 active/进行中、draft/草稿、paused/暂停 |
| 颜色 | 默认蓝色，支持现有课表颜色及对应英文值 |
| 备注 | 选填，最多 1000 字 |

预览逐行显示班级、教师、起止日期、时段、状态、课次数和字段错误。归档班级、非法日期、非本班教师、重复或重叠时段等会阻止整批确认。所有计划的课次总数最多 10000，整体日期跨度最多 731 天；不会静默截断。

## 冲突检查

检查本批进行中计划的课次与既有排课及实际课程、已登记课程对应的冻结计划快照，以及本批其他计划之间的重叠：

- 同一班级。
- 同一教师，包括跨班授课。
- 非空同名教室，包括跨班、跨教师。

结束时间等于另一课次的开始时间不冲突。草稿、暂停和单次停课不占资源；已登记课程的冻结快照仍保留占用。沿用原单条排课的规则，不恢复在班时段、在班起止日期或时间纠错验证。独立实际课程不被重新解释为排课计划。

预览列出冲突日期、时段、原因、对方排课及本批来源行。冲突总数完整统计，详情展示前 500 条；可在当前弹窗导出检查结果和已展示冲突。存在错误或冲突时不提供确认按钮，也不提供强制忽略冲突。

预览有效期 15 分钟。确认时重新检查管理员权限、班级版本、教师成员关系和全部资源冲突；预览后新增或调整排课会被再次检测。有变化时需重新预览，不会直接沿用旧结果写入。

## 统一创建与恢复

确认先在 `sms_teaching_plans` 准备带 `batchId` 的计划记录。准备记录不出现在课表、班级详情、导出或计划编辑接口。全部记录完整且校验通过后，单文档原子更新 `sms_schedule_batches.status` 为 `committed`，整批计划统一可见。读端只加载普通计划和已发布批次的计划，不需要 MongoDB 副本集事务。

排课、调课、课程登记和批量确认共用教学写入锁。写入过程定期续期，并使用批次令牌防止失效任务发布。重复确认已发布批次返回原结果，不重复创建；单条计划之后仍可正常编辑。

若进程中断或数据库写入失败，已准备的部分记录保持不可见。「批量排课 → 批次记录 → 详情」可继续创建；重试再次检查权限及冲突，沿用稳定计划 ID。其他插件管理员可以续办未发布批次。也可「放弃未发布批次」，仅清理该批未发布记录，已发布批次不能通过此入口删除。

`sms_schedule_batches` 保存预览、冲突、准备/发布状态和批次记录，未执行预览按 TTL 清理；准备或已发布批次保留恢复和审计依据。审计不包含完整备注或原始文件。

## API

复用 Hydro 登录会话及插件同源校验：

- `POST /sms/api/teaching/schedule-batches/parse`：`filename`、base64 `content`、可选 `sheet`，返回表格与建议列对应。
- `POST /sms/api/teaching/schedule-batches`：预览。传 `requestId`、`filename` 和解析后的 `headers/rows/mapping`；或传 `requestId/items`，每项为 `domainId` 加原排课字段。
- `GET /sms/api/teaching/schedule-batches`：最近 100 条已开始批次。
- `GET /sms/api/teaching/schedule-batches/:batch`：明细。
- `POST /sms/api/teaching/schedule-batches/:batch`：确认或续办，使用空 JSON 对象。
- `POST /sms/api/teaching/schedule-batches/:batch/cancel`：放弃未发布批次。
