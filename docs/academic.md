# 教务管理

入口：学生管理 → 教务管理（`/sms#academic`）。按班级、教师和日期筛选，查询区间最多 93 天。需要 `reports.read` 及对应班级 `courses.read`；计划课次还受 `schedules.read` 限制。学生个人数据不会自动进入教务报表。

## 课次跟进

按上海时区推导状态，不写入自动完成标志，不因查看而生成课程或考勤：

| 状态 | 条件 |
| --- | --- |
| 未开始 | 计划或实际课程尚未开始 |
| 上课时段 | 未关联实际课程，当前时间处于计划开始与结束之间 |
| 待录课程 | 计划已结束，尚未关联实际课程 |
| 考勤待补 | 已有实际课程但名单为空或至少一人未填写考勤 |
| 已完成 | 实际开始时间已到，参与名单非空且每人有考勤；迟到为有效考勤 |
| 已停课 / 草稿 | 按计划状态单独展示，不计有效计划 |

顶部卡片可筛选待录课程、考勤待补、已完成和需核对。计划与实际日期、开始或结束时间不一致时显示核对项。处理课次可继续登记实际课程、预览关联已有课程、调课、停课、恢复或安排补课，按钮依据具体操作权限显示。

从教务页面打开课程可直接修改教学内容与考勤，保存后刷新统计。编辑实际课程使用已经保存的参与名单，不会因班级后来新增成员而自动扩大原名单；历史离班成员考勤保留，已有有效考勤不能被省略。有相应权限时可搜索并补充其他可读学生，不进行在班时段校验。

## 统计口径

计划课次按计划日期统计；实际课程按实际上课日期统计。关联后不会把实际课程再算成一节独立计划，跨日期关联也不会在两个日期重复计入实际课程。

每日统计包含有效计划、停课、补课、实际课程、未关联排课的独立课程、每日去重学生数、参与人次，以及到课、迟到、请假、旷课、未填写人数。区间学生人数跨日期去重，不是每日人数的简单相加。计划和实际课程可以独立存在，名单只按保存的考勤行统计，不推断未登记学生缺勤。

每日统计、实际课程标签分别提供 Excel/CSV 导出，需额外具有覆盖当前筛选班级的 `reports.export`。不增加独立导出页，也不导出教师档案。

## 实现

- `src/academic.ts`：纯状态/考勤计数函数及受权限过滤的教务查询、分账统计、名单候选。
- `public/sms-addon/academic.js` / `academic.css`：响应式查询、状态卡片、课次与统计表格。
- `GET /sms/api/teaching/academic?classId=&teacherUid=&from=&to=&state=&page=`：跟进列表、完整区间状态汇总、每日及实际课程报表；课次分页每页 25 条。
- `GET /sms/api/classes/:id/roster-candidates?q=`：有名单补充权限者搜索可读学生基本姓名与 UID。
- `GET /sms/api/exports/academic-daily`、`academic-actual`：对应标签报表导出。

单区间最多返回 5000 条实际课程、10000 个课次；超过时要求缩小日期范围。教务操作复用原课程、排课、冲突锁、版本及审计，不增加另一套数据源。已舍弃的工作台、评语反馈、知识点掌握和独立公告不恢复。
